# LLM Response Evaluation Rubric & Annotation Guideline

**Document ID:** SOP-AI-EVAL-001  
**Version:** 2.0  
**Workflow:** Side-by-Side (SxS) Pairwise Model Evaluation (Response A vs. Response B)  
**Target Audience:** AI Data Annotators, Quality Assurance Specialists, Technical Evaluators  

---

## 1. Purpose & Scope

This guideline establishes standard operating procedures for evaluating, scoring, and ranking text outputs generated by Large Language Models (LLMs). The objective is to align annotator judgment, minimize subjectivity, and ensure data quality for Reinforcement Learning from Human Feedback (RLHF) workflows.

---

## 2. Core Evaluation Dimensions

Evaluators must assess model outputs across four primary parameters, ranked in order of priority:

1. **Truthfulness & Factuality (Critical):** Claims must be supported by verifiable real-world facts or provided context. Hallucinations result in an automatic failure.
2. **Instruction Following (Critical):** The response must satisfy all explicit constraints in the prompt (e.g., tone, formatting, word count, code language).
3. **Helpfulness & Completeness:** The output must directly address the user intent without omitting vital steps or adding irrelevant filler.
4. **Safety & Policy Compliance (Mandatory Pass):** Outputs must strictly comply with safety guidelines (no hate speech, unsafe medical/legal advice, or malicious code).

---

## 3. Pairwise Comparison Scale (Response A vs. Response B)

When performing Side-by-Side (SxS) comparison, select one of the following ratings:

| Rating | Definition | Selection Criteria |
| :--- | :--- | :--- |
| **A is Much Better** | Preference > 80% | Response A addresses all constraints accurately; Response B contains critical hallucinations or fails basic instructions. |
| **A is Slightly Better** | Preference ~ 60% | Both responses are accurate, but Response A is better structured, more concise, or easier to read. |
| **About Equal** | Neutral | Both responses are equally accurate/helpful or both exhibit minor, non-critical flaws. |
| **B is Slightly Better** | Preference ~ 60% | Response B is slightly superior in conciseness, formatting, or clarity. |
| **B is Much Better** | Preference > 80% | Response B satisfies all prompt requirements while Response A violates safety, factual, or formatting rules. |

---

Follow this sequential workflow for every evaluation task:

         ▼

         │

         │
