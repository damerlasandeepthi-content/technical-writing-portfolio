# Technical Writing & API Documentation Portfolio

Welcome to my technical writing portfolio. This repository showcases developer-facing documentation, OpenAPI specifications, and API integration guides.

## Featured Project: Weather API Developer Guide & OpenAPI Spec

### Overview
A developer-focused documentation suite for a RESTful Weather API, designed to help engineers authenticate, construct HTTP requests, and process structured JSON responses.

### Core Deliverables
* **Developer Quickstart Guide:** [`quickstart-guide.md`](./quickstart-guide.md) — Step-by-step onboarding with cURL and Python code examples.
* **OpenAPI 3.0 Specification:** [`openapi-spec.json`](./openapi-spec.json) — Machine-readable schema defining endpoints, request parameters, and status responses.
